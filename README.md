# MiCeramica

MiCeramica vende productos de cerámica para el hogar y la decoración.

## Nuestro negocio

- Qué vendemos: productos de cerámica para el hogar y la decoración.
- A quién le vendemos: personas que buscan decorar y equipar su hogar.
- Cómo llega el pedido: preparamos el pedido y lo enviamos al domicilio del cliente.
